# CLI Task Manager

A command-line task manager built using Python and argparse.

## Features

- Add tasks
- View tasks
- Mark tasks as complete
- Delete tasks
- Update task titles
- Search tasks
- Sort tasks by priority
- Persistent JSON storage
- Colored terminal output
- Command-line interface using argparse

---

## Tech Stack

- Python
- argparse
- JSON
- colorama

---

## Installation
